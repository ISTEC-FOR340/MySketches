## 2025-05-14 - Semantic Navigation and Interaction Precision

**Learning:** Replacing non-semantic interactive containers (like `div` with `onclick`) with semantic `<a>` tags not only improves screen reader compatibility but also simplifies JavaScript by leveraging native browser navigation. Additionally, providing real-time numeric feedback for range sliders significantly reduces user uncertainty in generative art interfaces.

**Action:** Always prioritize semantic `<a>` or `<button>` tags for interactive elements and ensure all range sliders have adjacent value displays for better UX control.
