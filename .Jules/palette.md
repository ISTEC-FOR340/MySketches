## 2026-05-29 - Semantic Card Navigation and Focus Visibility
**Learning:** Refactoring non-semantic interactive containers (like `div` with `onclick`) to semantic `<a>` tags not only improves accessibility but also allows for cleaner code by removing manual event listeners. When using large interactive cards, nested buttons should be converted to non-interactive elements (like `span`) with `aria-hidden="true"` to avoid "interactive content within interactive content" which confuses screen readers. Additionally, setting `overflow: visible` on cards is essential when using custom focus rings (like `box-shadow`) to prevent them from being clipped by the card's boundaries.
**Action:** Always prefer semantic `<a>` or `<button>` for interactive containers, sanitize nested interactivity, and ensure container `overflow` settings accommodate focus indicators.
