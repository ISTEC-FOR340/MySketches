## 2025-05-14 - Semantic Navigation and Focus Management
**Learning:** Transitioning from JavaScript-based navigation to semantic HTML `<a>` tags significantly improves accessibility and simplifies code. For complex interactive cards, using `:focus-visible` to match hover effects ensures a consistent experience for keyboard users.
**Action:** Always prefer semantic links for navigation. Use `overflow: visible` on containers when implementing custom focus rings to prevent clipping.
